# Продукт: Chief Hub

## Для кого

Шеф-бариста сети спешелти-кофеен из трёх и более точек. Не привязан к конкретной компании: все названия, нормы и планы настраиваются.

Три стадии, которые инструмент должен вести подряд:

1. **День 0.** Человек только вошёл в должность и не знает, с чего начать. Нужен понятный план и место, где копится картина сети.
2. **Первые месяцы.** Нужно ввести стандарты, увидеть команду, поймать отклонения по качеству и складу.
3. **Сеть.** Нужно сравнивать точки, растить старших бариста, передавать контроль и открывать новые точки по чек-листу.

## Принципы

- **Шаблон, но не клетка.** Всё работает из коробки, но точки, разделы, нормы и план редактируются.
- **Сигналы вместо таблиц.** Главный экран отвечает на вопрос «что сегодня требует моего внимания».
- **Ввод за 10 секунд.** Записать настройку помола или остатки можно с телефона, стоя у кофемашины.
- **Без обязательного обучения.** Каждый раздел понятен без инструкции.
- **Данные принадлежат владельцу.** Выгрузка в файл в один клик, никакой привязки к закрытым сервисам.

## Разделы и логика

### Обзор
Недельные KPI по выбранной области (вся сеть или одна точка), список проблем (настройки вне нормы, позиции ниже минимума), прогресс «Пути шефа».

### Путь шефа
Четыре этапа: «Осмотреться» (день 0–7), «Стабилизировать» (8–30), «Усилить» (31–90), «Масштабировать» (от 90). Пункты отмечаются галочками. Универсальный список лежит в `src/config.ts`.

### Команда
Шесть навыков (эспрессо, молоко, фильтр, настройка помола, чистота, сервис), четыре уровня (— / учится / уверенно / может учить). Раздел подсвечивает самый слабый навык по выбранной области.

### Качество
- Журнал настройки помола: доза, выход, время.
- Автооценка по нормам: выход ≈ доза × соотношение с допуском, время в заданном диапазоне.
- Стабильность точки = доля записей в норме.
- Каппинги с баллами и дескрипторами.

### Склад
Остатки по каждой точке, минимум на позицию, подсветка нехватки, суммарный список закупки (с кнопкой «Скопировать»).

### Показатели
Недельные данные: выручка, чеки, себестоимость. Диаграмма по неделям, сравнение точек, средний чек.

### Настройки
Название сети, валюта, точки, включение разделов, нормы эспрессо, выгрузка/загрузка данных.

## Модель данных (кратко)

- **Точка:** название.
- **Сотрудник:** имя, должность, точка, уровни навыков.
- **Запись настройки:** точка, дата, доза, выход, время, заметка.
- **Каппинг:** точка, дата, кофе, балл, дескрипторы.
- **Позиция склада:** название, категория, единица, минимум, остатки по точкам.
- **Недельная запись:** точка, неделя, выручка, чеки, себестоимость %.

## Что пока сознательно не делаем

Интеграции с кассой, учёт зарплат, закупочные накладные, расписание смен. Они в roadmap, но тянут за собой облако и роли доступа.
