# Roadmap

Порядок отражает ценность для шефа: сначала то, без чего инструмент нельзя использовать командой.

## v0.1 — прототип (сейчас)
- [x] Семь разделов на демо-данных
- [x] Мобильная и десктопная раскладка, тёмная тема
- [x] Установка как приложение (PWA), работа без сети
- [x] Выгрузка и загрузка данных файлом
- [x] Автоматическая копия на Google Диск: таблица по разделам и копии данных за 30 дней
- [ ] Восстановление с Google Диска одной кнопкой (без скачивания файла)
- [ ] Недельный отчёт как Google Документ
- [x] Автопубликация на GitHub Pages
- [ ] Первая сборка на GitHub без ошибок

## v0.1.1 — по должностной инструкции (сделано)
- [x] Порядок разделов повторяет инструкцию шеф-бариста для Москвы
- [x] «Путь шефа» с рубежами 7, 30, 60, 90 дней
- [x] «Путь шефа» по актуальной панели: шаги под склад, инвентаризации и себестоимость, «Готово, когда…», переход в раздел, итог 90 дней
- [x] «Путь шефа»: заметки к шагу (итог, что всплыло), блок «Для разбора», свои шаги, лист на Диске
- [x] Оборудование: график ТО, заявки на ремонт
- [x] Обходы: чек-лист, тайный гость, жалобы гостей
- [x] Обходы: закрытие жалобы с действием (исправлено / разобрано с сотрудником / без действий), датой и пояснением; счётчики за 30 дней в отчёте
- [x] Обходы: заметка к пункту при оценке «частично» или «нет»
- [x] Обходы: аудит шеф-бариста вместо санитарного чек-листа, короткий бланк тайного гостя, жалобы и похвалы в одном списке
- [x] Отчёт: недельный, собирается из данных, копируется одной кнопкой
- [x] Команда: записи аттестаций и срок их действия
- [x] Команда: заметка аттестации видна в таблице и на Диске; подсказка «Как оценивать» по уровням навыков
- [x] Склад: списания с причинами, несколько позиций за один раз
- [x] Склад: банк ингредиентов из стандартов, сток из приходов, списаний и продаж за день, единицы г/мл/шт → кг/л/шт, точки по галочкам
- [x] Качество: стандарты напитков (ТТК) без версий и фото
- [x] Обзор: показатели по инструкции и общий список сигналов
- [x] Данные версии 2 с миграцией со старой версии

## v0.2 — общая работа команды
- [ ] Облачное хранилище (Supabase) и вход по почте
- [ ] Роли и доступ по точкам: владелец, шеф, управляющий, бариста
- [ ] Журнал изменений: кто и когда внёс запись

## v0.3 — управление людьми
- [ ] Онбординг нового бариста: чек-листы на 2 недели
- [ ] Аттестации: тесты и практические задания по навыкам
- [ ] План развития на сотрудника, отметка «готов к повышению»
- [ ] Чек-листы открытия и закрытия по точкам

## v0.4 — качество и меню
- [ ] Карточки рецептур с версиями и фото
- [ ] Калибровочные сессии и протоколы каппинга (формы SCA)
- [ ] Тренды: как менялась стабильность точки за месяц
- [ ] Отслеживание обжарки, партий зерна, срока годности

## v0.5 — склад и закупки
- [ ] Поставщики, цены, история закупок
- [x] Инвентаризация: факт, расхождения, проблемные позиции и выборочный пересчёт
- [ ] Инвентаризация со сканированием и фото полок
- [x] Влияние списаний на себестоимость: списания в рублях внутри расхода периода
- [ ] Заказ поставщику из списка закупки

## v0.6 — аналитика сети
- [x] Показатели: выручка по дням и точкам (общая, бар, чеки, гости), итоги за неделю, месяц, год и сравнения
- [x] Приходы с суммой по накладной с НДС и средняя цена ингредиента по сети (этап 2)
- [x] Себестоимость по инвентаризации: расход в рублях между двумя инвентаризациями, % от выручки бара (этап 3)
- [x] Себестоимость по ТТК: стоимость порции, себестоимость по дням из «Расхода за день», факт против ТТК по позициям за период инвентаризации (этап 4, продажи вносятся вручную)
- [ ] Выгрузка продаж по позициям из кассы файлом и связка названий кассы со стандартами (замена ручного «Расхода за день»)
- [ ] Импорт выручки из кассовых систем (CSV, затем API)
- [ ] Цели и KPI по точкам, динамика к цели
- [ ] Автоматический недельный отчёт по сети

## v0.7 — рост сети
- [ ] Шаблон открытия новой точки: чек-лист, оборудование, найм, запуск
- [ ] Стандарты сети как документы с отметкой «ознакомлен»
- [ ] Редактор плана «Путь шефа» прямо в интерфейсе (свои шаги из заметок уже есть; осталось менять и скрывать стандартные)
- [ ] Несколько языков интерфейса
