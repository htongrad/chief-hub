# Roadmap

Порядок отражает ценность для шефа: сначала то, без чего инструмент нельзя использовать командой.

## v0.1 — прототип (сейчас)
- [x] Семь разделов на демо-данных
- [x] Мобильная и десктопная раскладка, тёмная тема
- [x] Установка как приложение (PWA), работа без сети
- [x] Выгрузка и загрузка данных файлом
- [x] Автопубликация на GitHub Pages
- [ ] Первая сборка на GitHub без ошибок

## v0.2 — общая работа команды
- [ ] Облачное хранилище (Supabase) и вход по почте
- [ ] Роли и доступ по точкам: владелец, шеф, управляющий, бариста
- [ ] Журнал изменений: кто и когда внёс запись

## v0.3 — управление людьми
- [ ] Онбординг нового бариста: чек-листы на 2 недели
- [ ] Аттестации: тесты и практические задания по навыкам
- [ ] План развития на сотрудника, отметка «готов к повышению»
- [ ] Чек-листы открытия и закрытия по точкам

## v0.4 — качество и меню
- [ ] Карточки рецептур с версиями и фото
- [ ] Калибровочные сессии и протоколы каппинга (формы SCA)
- [ ] Тренды: как менялась стабильность точки за месяц
- [ ] Отслеживание обжарки, партий зерна, срока годности

## v0.5 — склад и закупки
- [ ] Поставщики, цены, история закупок
- [ ] Инвентаризация по списку с телефона
- [ ] Списания и причины, влияние на себестоимость
- [ ] Заказ поставщику из списка закупки

## v0.6 — аналитика сети
- [ ] Импорт выручки из кассовых систем (CSV, затем API)
- [ ] Цели и KPI по точкам, динамика к цели
- [ ] Автоматический недельный отчёт по сети

## v0.7 — рост сети
- [ ] Шаблон открытия новой точки: чек-лист, оборудование, найм, запуск
- [ ] Стандарты сети как документы с отметкой «ознакомлен»
- [ ] Редактор плана «Путь шефа» прямо в интерфейсе
- [ ] Несколько языков интерфейса

## Идеи без срока
- Push-уведомления (отклонение настройки, нехватка на складе)
- Экспорт отчётов в PDF
- Публикация в App Store и Google Play через Capacitor
