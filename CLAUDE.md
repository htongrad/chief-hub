# Chief Hub: инструкции для Claude

Универсальная панель шеф-бариста для сети спешелти-кофеен (3+ точек). React + TypeScript + Vite, PWA, публикация через GitHub Pages. Реалии конкретной компании не использовать: всё общее и настраиваемое.

## Пользователь
Не программист, работает с телефона. Объяснять простыми словами. Шаги вне кода (GitHub, настройки) давать короткой нумерованной инструкцией под телефон.

## Экономия лимитов
- Отвечать коротко, править только нужные файлы, не пересоздавать проект.
- Перед нетривиальной задачей назвать подходящую модель: Haiku (мелкие правки, тексты), Sonnet (разделы, баги, основная работа), Opus (облако, роли доступа, смена структуры данных, сложные ошибки). Если задача проще текущей модели, предложить переключиться.
- Не тратить шаги на долгие обзоры репозитория: структура описана в docs/ARCHITECTURE.md.

## Правила работы с кодом
- Разделы лежат в `src/modules/`, реестр разделов, навыки и план шефа в `src/config.ts`, данные и расчёты в `src/store.tsx`, типы в `src/types.ts`.
- Новое поле данных: добавить в `types.ts` и `seed.ts`; при смене формы поднять `version`.
- Перед завершением запускать `npm run build`. Если не получилось запустить, сказать об этом прямо.
- Публикация: слияние в ветку `main` запускает автодеплой (`.github/workflows/deploy.yml`).
- При изменении продукта обновлять README.md и документы в docs/.
