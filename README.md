# Chief Hub — панель шеф-бариста

Рабочий инструмент для шеф-бариста сети спешелти-кофеен (от 3 точек). Одинаково подходит человеку в первый день в должности и руководителю целой сети: разделы включаются и выключаются, точки добавляются, нормы настраиваются.

Работает как сайт и ставится на телефон как приложение (Android и iPhone) без магазинов приложений.

## Что внутри

| Раздел | Зачем |
|---|---|
| **Обзор** | Выручка, чек, себестоимость, тревожные сигналы по складу и качеству, прогресс плана |
| **Путь шефа** | Пошаговый план: первая неделя → 30 дней → 90 дней → масштабирование на сеть |
| **Команда** | Сотрудники и матрица навыков, слабое место команды |
| **Качество** | Журнал настройки помола с автопроверкой по нормам, каппинги, стабильность по точкам |
| **Склад** | Остатки по точкам, минимумы, автоматический список закупки |
| **Показатели** | Выручка по неделям, сравнение точек, средний чек, себестоимость |
| **Настройки** | Точки, включение разделов, нормы эспрессо, выгрузка и загрузка данных |

В приложении лежат вымышленные демо-данные, чтобы сразу было видно, как всё работает. Их можно очистить в «Настройки → Данные».

## Как опубликовать на GitHub (без программирования)

1. Создайте аккаунт на github.com и нажмите **New repository**. Название, например, `chief-hub`. Выберите Public или Private.
2. На странице нового репозитория нажмите **uploading an existing file** и перетащите туда всё содержимое этой папки (включая скрытую папку `.github`). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В поле **Source** выберите **GitHub Actions**.
4. Перейдите во вкладку **Actions** и дождитесь зелёной галочки у задачи *Deploy to GitHub Pages* (1–3 минуты).
5. Адрес сайта появится в **Settings → Pages**. Он выглядит как `https://ваш-логин.github.io/chief-hub/`.

> Для приватного репозитория GitHub Pages доступен на платных тарифах. На бесплатном тарифе репозиторий должен быть публичным. Данные всё равно остаются только у вас в браузере, в репозитории хранится лишь код.

После этого при каждом изменении файлов в репозитории сайт обновляется автоматически.

## Установка на телефон

- **iPhone:** откройте сайт в Safari → «Поделиться» → «На экран Домой».
- **Android:** откройте сайт в Chrome → меню ⋮ → «Установить приложение».

## Где хранятся данные

Сейчас всё хранится в браузере конкретного устройства. Это значит:

- данные с телефона не появятся на компьютере сами по себе;
- если очистить данные браузера, они пропадут.

Пока облако не подключено, регулярно нажимайте **Настройки → Скачать данные** и храните файл. Подключение общего облака (чтобы вся команда видела одни данные) описано в [docs/ROADMAP.md](docs/ROADMAP.md), это первая задача следующего этапа.

## Для разработчика

```bash
npm install
npm run dev        # запуск на localhost
npm run build      # проверка типов и сборка в dist/
```

Стек: React 18, TypeScript, Vite. Структура и принципы: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Описание продукта: [docs/PRODUCT.md](docs/PRODUCT.md).
